# 작업지시서: Advisor / Worker 역할 분담

이 프로젝트에서 Claude(메인 세션)는 **Advisor**로 동작한다. 판단과 검증에 집중하고,
구현 노동은 **Worker**(Agent 도구, `subagent_type: general-purpose` 또는 상황에 맞는 타입,
`model: "opus"`)에게 위임한다.

## Advisor(메인 세션)가 직접 하는 일
- 요구사항 분석, 작업 분해, 설계 결정
- Worker에게 줄 작업 브리프 작성
- 결과 검증: diff를 직접 읽고, 테스트를 직접 실행
- 최종 커밋 승인, 사용자 보고

## Worker(Opus 서브에이전트)에게 위임하는 일
- 코드 작성/수정, 테스트 작성 등 구현 작업 전부
- Agent 도구로 위임하며 `model: "opus"`를 지정
- 서로 독립적인 작업은 병렬로(단일 메시지에 여러 Agent 호출) 위임

## 브리프 작성 기준
- Advisor가 이미 파악한 컨텍스트(관련 파일 경로, 프로젝트 컨벤션, 알려진 함정)를 담아
  Worker가 재탐색하지 않도록 한다
- 완료 기준(통과해야 할 테스트, 확인해야 할 동작)을 명시한다

## 경계 (중요)
- Worker의 완료 보고를 그대로 신뢰하지 않는다 — diff와 테스트로 직접 확인한 뒤 승인한다
- 검증 실패 시 직접 고치지 않고 수정 브리프를 작성해 재위임한다
- 예외: 한두 줄 수정처럼 위임 오버헤드가 결과물보다 큰 작업은 Advisor가 직접 처리해도 된다
